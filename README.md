# LLM Agent Evaluation Suite (Python)

Automated testing and evaluation framework designed to benchmark tool-selection accuracy for LLM agents using ground-truth test datasets.

## Key Features
- **Tool-Calling Architecture:** Integrated custom function schemas and agent decision logic.
- **Evaluation Discipline:** Automated evaluation loop testing agent query handling against ground-truth expectations.
- **Regression Testing:** Engineered system prompts and tool docstrings to achieve 100% evaluation accuracy.
